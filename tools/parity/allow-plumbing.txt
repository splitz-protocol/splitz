# Divergences between the two plumbing surfaces that are idiom rather than gap.
#
# The Dart side is `package:splitz_host`'s `lib/src/`, which its barrel
# re-exports whole. The Rust side is `rust/splitz-host/src/lib.rs`'s `pub use`
# block — the names a consumer reaches as `splitz_host::…`. A name that is
# `pub` inside a module but not re-exported is not surface.
#
# Names are compared with Rust's snake case mapped onto Dart's camel case
# automatically, because that difference carries no meaning. A type keeps its
# capitals in both languages.
#
# Every line states why a name exists on one side and not the other. A line
# with no reason is a suppression, and a stale line fails this lane so the
# list cannot outlive what it describes.

# --- a refusal is a thrown exception in Dart and a returned error in Rust ---
dart::SealingException   # Rust returns `HostError::Sealing`. One enum for every refusal this layer makes, because a Rust caller matches on it rather than catching by type.
dart::SplitsRelayException  # `HostError::Relay { transient }` — §15.5's "could retrying succeed" is a field there and a constructor argument here.
dart::SplitsSyncException   # `HostError::Sync`.
dart::SwapException         # `HostError::Swap { transient }`.
dart::SwapRefused           # `HostError::SwapRefused`, carrying the `SwapSendRefusal` a combined send's swap leg was refused with.
dart::BillKeyConflict       # `HostError::KeyConflict`, naming the bill.
dart::BillStorageUnreadable # `HostError::Unreadable`, naming the key: §15.4's read raising on a value that is there and cannot be read.
dart::SendInFlight          # `HostError::SendInFlight { pending }`, carrying the earlier send when one is written down.
dart::UnrecordableReason    # The variants of Rust's `Unrecordable` enum, which carries them directly; Dart's `Unrecordable` exception carries one of these.
dart::UnsentClaim         # The variants of Rust's `UnsentClaimRefusal` enum, whose `BuiltSince` carries the txid directly; Dart's `UnsentClaimRefusal` class carries one of these and the txid beside it.
dart::SwapSendRefused     # The variants of Rust's `SwapSendRefusal` enum, which carries `Held { paid_to }` directly; Dart's `SwapSendRefusal` class carries one of these and the `paidTo` list.
dart::UnansweredSignatureQuestion  # `FoldFailure::Unanswered`, one of the two ways a verified fold fails. Dart throws it past a fold that returns.
rust::HostError          # The enum the four above collapse into.
rust::Result             # `Result<T> = core::result::Result<T, HostError>`. Dart throws, so there is no alias to name.
rust::FoldFailure        # A verified fold fails either because the log was refused or because a signature question went unanswered; Rust returns the pair, Dart throws two types.

# --- Dart hangs a constant or a helper on a class; Rust puts it on the crate
# --- root, which is where a consumer reaches it.
dart::SplitsSigner       # Rust's `Signer`. Its `encode`/`decode`/`seedBytes` statics are `base64url_encode`, `base64url_decode` and `SEED_BYTES` below.
dart::SplitsSealing      # Rust's `Sealing`. Its `blobVersion` static is `BLOB_VERSION` below.
dart::SplitsChannel      # A class holding one static, `forBill`. Rust's `channel_for_bill` is the function itself.
rust::Signer             # Named without the prefix: a crate is already a namespace.
rust::Sealing            # The same.
rust::channel_for_bill   # `SplitsChannel.forBill`.
rust::base64url_encode   # `SplitsSigner.encode`.
rust::base64url_decode   # `SplitsSigner.decode`.
rust::is_well_formed_key # `SplitsKeys.isWellFormedKey`.
rust::SEED_BYTES         # `SplitsSigner.seedBytes`.
rust::BLOB_VERSION       # `SplitsSealing.blobVersion`.
rust::KEY_LENGTH_BYTES   # `SplitsKeys.keyLengthBytes`.
rust::IDENTITY_DOMAIN    # `SplitsKeys.identityDomain`.

# --- a shape one language needs a name for and the other does not -----------
dart::JsonPost           # Dart names the two calls as two typedefs; Rust takes one `HttpTransport` trait with both, because a Rust caller implements one thing.
dart::JsonGet            # The other half of the same pair.
rust::HttpTransport      # The trait those two typedefs become.
dart::ZecAssetId         # A typedef for `String`. Rust takes the id as a `&str` parameter, which needs no name.
dart::SplitKindWire      # An extension carrying `wireType`. Rust puts the method on `SplitKind` itself, where an enum may have one.
rust::Randomness         # Dart's `SplitsKeys` takes `dart:math`'s `Random`; Rust has no such type in its standard library, so the seam names the shape it needs.
rust::SystemRandomness   # The platform entropy behind it. Dart reaches `Random.secure()` directly.
rust::query_encode       # Dart builds a URL with `Uri.replace(queryParameters:)`; Rust states the encoding rather than depending on a URL crate, because two libraries disagree about the sub-delimiters and a status query that addresses a different swap is not a cosmetic difference.
rust::component_encode   # The same, for `Uri.encodeComponent`, which keys a swap watch.

# --- deliberately not in the crate ------------------------------------------
dart::FileBillStorage    # A file-backed §15.4 store. The Rust crate is reached across a foreign binding, where the wallet supplies storage — one in the crate would have no caller. `InMemoryBillStorage` is there for tests on both sides.
dart::FileSecretStore    # The same, for §15.3. A shipped build puts secrets in the platform keychain, which is the wallet's.

# --- a development run's own fixtures, Dart only ----------------------------
# `lib/src/testing/` exists so a real-transaction run on a device can be
# pointed at known wallets and fetch a seed phrase from loopback at run time
# rather than from a `--dart-define` that would be compiled into the binary.
# It drives a Flutter integration test; the Rust crate has no such run and
# would have no caller for any of it.
dart::SeedDriver         # The loopback listener a run fetches a phrase from.
dart::SeedDriverException  # What it raises when it is not running or will not bind.
dart::SeedFetch          # The call that fetches one.

# --- the 1Click shape, as values rather than calls ---------------------------
# A provider is reached over HTTP and HTTP is the wallet's; what the request
# looks like and what the answer means are not. Rust states those four as
# functions over text so that a caller making its own request — a foreign
# binding, a wallet with its own client — reads the answer the way
# `OneClickSwaps` does. Dart's `OneClickSwaps` keeps them inside itself.
rust::quote_request_body   # The body a quote request carries. Dart builds it inside `OneClickSwaps.quote`.
rust::assets_from_tokens   # What a `/v0/tokens` answer lists. Dart's `_asset` and the loop in `tradableAssets`.
rust::quote_from_response  # What a `/v0/quote` answer states. Dart reads it inline in `quote`.
rust::status_from_response # What a `/v0/status` answer means. Dart reads it inline in `statusOf`.

dart::price_from_coin_gecko    # `price_from_coingecko`: Dart camel-cases the brand as `CoinGecko`, so the mechanical snake case splits it.
rust::price_from_coingecko     # `priceFromCoinGecko`.
dart::iso4217_exponents        # `ISO_4217_EXPONENTS`: a Dart top-level constant is lower camel case, a Rust one upper snake case.
rust::ISO_4217_EXPONENTS       # `iso4217Exponents`.
dart::max_minor_units_per_zec  # `MAX_MINOR_UNITS_PER_ZEC`, as above.
rust::MAX_MINOR_UNITS_PER_ZEC  # `maxMinorUnitsPerZec`.
dart::max_account_index        # `MAX_ACCOUNT_INDEX`, as above.
rust::MAX_ACCOUNT_INDEX        # `maxAccountIndex`.
dart::max_token_decimals       # `MAX_TOKEN_DECIMALS`, as above.
rust::MAX_TOKEN_DECIMALS       # `maxTokenDecimals`.
dart::max_parse_exponent       # `MAX_PARSE_EXPONENT`, as above.
rust::MAX_PARSE_EXPONENT       # `maxParseExponent`.
dart::rate_warning_percent     # `RATE_WARNING_PERCENT`, as above.
rust::RATE_WARNING_PERCENT     # `rateWarningPercent`.
dart::BillNaming               # Dart carries `displayNameOf`, `sharedNames` and `shortId` as an extension on `Bill`, which is how a screen reads them; Rust declares `display_name_of`, `shared_names` and `short_id` as functions taking the bill.
rust::display_name_of          # `BillNaming.displayNameOf`.
rust::shared_names             # `BillNaming.sharedNames`.
rust::short_id                 # `BillNaming.shortId`.
rust::coingecko_price_url      # `CoinGeckoZecPrices.requestFor`: Rust lifts it to the crate so the binding and the client share one spelling.
dart::binance_zec_symbol       # `BINANCE_ZEC_SYMBOL`: a Rust constant is upper-case, so the mechanical snake case differs.
rust::BINANCE_ZEC_SYMBOL       # `binanceZecSymbol`.
rust::binance_price_url        # `BinanceZecPrices.request`: Rust lifts it to the crate as it does `coingecko_price_url`.
rust::coinbase_price_url       # `CoinbaseZecPrices.request`: the same.

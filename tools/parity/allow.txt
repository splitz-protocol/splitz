# Divergences surface.py must not fail on, and why.
#
# A bare name is an idiom divergence: the two languages spell one thing
# differently and both spellings are correct. Anything not listed here is a
# gap, and the lane exits non-zero for it.

# The refusal codes of SPEC.md section 12. Rust exposes them as `pub const` in
# a `code` module; Dart as static members of `SplitCode`, which the extractor
# reads as one name rather than seventy-three. Both expose every code.
dart::SplitCode

# Dart throws and Rust returns; each needs a helper the other has no use for.
dart::raise
rust::Result

# Dart names the confirmation rule as a class with fields; Rust returns a
# tuple from `confirmation_rule`. The same three facts either way.
dart::ConfirmationRule

# A named type for the owed-per-participant map. Dart uses Map<String, int>
# directly, which needs no alias.
rust::Shares

# Dart takes base64url from dart:convert; Rust writes it out, since the crate
# takes no dependency for it.
rust::base64url

# The individual code constants covered by the note above.

# Dart names the host's verifier as a typedef; Rust takes it as a generic
# `impl Fn` bound, which has no name to expose.
dart::VerifySignature
